# Chavali Uddipa Dattudu — GitHub Pages Portfolio

This is a static HTML/CSS portfolio prepared for GitHub Pages. The visual theme is intentionally unchanged: light violet / Brooklyn-inspired styling.

## 1. Create the GitHub Pages repository

Create a new **public** repository named exactly:

`chavali-uddipa-dattudu.github.io`

The repository name follows GitHub's required `<username>.github.io` format for a user site.

## 2. Upload the portfolio files

Upload these files/folders to the repository root:

- `index.html`
- `style.css`
- `resume.pdf`
- `.nojekyll`
- `robots.txt`
- `sitemap.xml`
- `images/` (your existing image folders and files)

Important: this package intentionally does **not** include your `images/` folder, as requested. Copy your existing `images/` folder into the repository root so the current image paths continue to work.

## 3. Enable GitHub Pages

In the repository:

**Settings → Pages → Build and deployment → Source → Deploy from a branch**

Select:

- Branch: `main`
- Folder: `/ (root)`

Then click **Save**.

Your site should publish at:

`https://chavali-uddipa-dattudu.github.io/`

GitHub documents branch-based publishing and the `/ (root)` option in its Pages setup documentation.

## 4. Commit/update workflow

Whenever you make changes, commit them to `main`. GitHub Pages will publish updates from the selected source.
